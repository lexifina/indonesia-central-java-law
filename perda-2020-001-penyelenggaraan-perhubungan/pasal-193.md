# Pasal 193
(1) Pembangunan jalur kereta api khusus yang memerlukan perpotongan dengan jalur kereta api umum, jalan, terusan, saluran air dan/atau prasarana lain dibuat tidak sebidang.
(2) Dalam hal perpotongan dilakukan pada jalur kereta api khusus yang sudah ada, harus mendapatkan izin dari pemilik prasarana perkeretaapian khusus.
(3) Penyelenggara perkeretaapian khusus wajib mengizinkan perpotongan tidak sebidang terhadap pembangunan jalur kereta api umum, jalan, terusan, saluran air dan/atau prasarana lain untuk kepentingan umum sesuai ketentuan peraturan perundag-undangan.
