# Pasal 202
(1) Tarif angkutan kereta api terdiri dari tarif angkutan orang dan tarif angkutan barang.
(2) Tarif angkutan sebagaimana dimaksud pada ayat (1) ditetapkan berdasarkan perhitungan modal, biaya operasi, biaya perawatan, dan keuntungan.
(3) Tarif angkutan orang ditetapkan oleh penyelenggara sarana perkeretaapian berdasarkan pedoman yang ditetapkan oleh Pemerintah.
(4) Gubernur dapat menetapkan tarif angkutan orang antar Kota dalam Daerah dan perkotaan dalam Daerah, meliputi:
a. angkutan pelayanan kelas ekonomi; dan b. angkutan perintis.
(5) Ketentuan lebi lanjut terkait tarif angkutan kereta api diatur lebih lanjut dengan Peraturan Gubernur.
