# Pasal 129
(1) Tatanan perkeretaapian Daerah meliputi jenis kereta api dan fungsi perkeretaapian.
(2) Jenis kereta api sebagaimana dimaksud pada ayat (1) meliputi :
a. kereta api kecepatan normal;
b. kereta api kecepatan tinggi;
c. kereta api monorel;
d. kereta api motor induksi linear;
e. kereta api gerak udara;
f. kereta api levitasi magnetik;
g. trem; dan h. kereta gantung.
(3) Fungsi perkeretaapian sebagaimana dimaksud pada ayat (1), mencakup :
a. perkeretaapian umum; dan b. perkeretaapian khusus.
